# SecondLife – Community Sharing Platform

## Project Description

SecondLife is a Java desktop application developed using Java Swing. It helps community members list items they no longer need for donation, exchange, pet adoption, and pet fostering.

The application allows users to add listings, attach photographs, search and filter listings, view details, update listing status, mark listings as completed, and delete listings. Listing data is stored locally using Java object serialization.

## Technologies Used

- Java
- Java Swing
- Java AWT
- Java Collections Framework
- File Handling and Serialization
- ImageIO and ImageIcon

## Main Features

- Add new community listings
- Attach photographs to listings
- Search listings by keyword
- Filter by category and listing type
- View complete listing details
- Change listing status
- Mark listings as completed
- Delete listings
- Save and load listing data locally

## Requirements

- Java Development Kit (JDK)
- A Java IDE such as IntelliJ IDEA, Eclipse, or NetBeans, or a terminal with Java configured

## Steps to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Ensure that the JDK is installed and configured.
4. Open a terminal in the folder containing `SecondLife.java`.
5. Compile the program:

   `javac SecondLife.java`

6. Run the application:

   `java SecondLife`

## Data Storage

The application stores listing records in `secondlife_data.dat` and photographs in the `secondlife_photos` folder. These files are created locally when needed.

## Project Scope

This is a local Java desktop application. It does not currently provide online user accounts, a central online database, or automatic sharing of listings between computers.
